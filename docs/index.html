PartePlay

Practice along with the real performance — locked to your score's transport.

Free, open-source VST3. Load a reference recording (WAV, FLAC, OGG, MP3) and PartePlay plays it in sync with the host transport: play, pause, seek, rewind — never drifts, never needs manual re-alignment. Slow it to 50%, loop a passage, and confirm the tuning of the file with one glance. Fully localized in four languages, and fingerprints the file offline.

Why it exists

A metronome keeps time, but a real performance keeps music. The problem is keeping a reference recording aligned with the score while you practice in pieces — restarting, looping, stopping. PartePlay treats the audio as a score follower that obeys the host clock instead of its own, so the alignment problem disappears.

What it does today

Host-locked playback

Audio position derives from the DAW/notation transport (timeInSamples). No internal clock to drift.

Training mode

Speed 50–150% plus bar-based looping aligned to the detected meter — with sync preserved.

Tuning reference

Detects the file's tuning (Hz) and compensates against your reference (432–445 Hz, default 440). Ratio 1.0 plays the original buffer untouched.

Tempo analysis

BPM, meter (3/4 or 4/4), bar count and tuning, with MIDI 1.0 time-map export for MuseScore and DAWs.

Offline fingerprint

Computes an AcoustID-compatible fingerprint locally (Chromaprint). No cloud, no key in the binary. Online matching and submissions are intentionally off.

Four locales

pt-BR · en-GB · en-US · es-ES, switchable in the editor. Numbers use each locale's decimal separator.

Install

  1. Close MuseScore (or your DAW) — the binary is locked while the plugin is loaded.
  2. Run the installer script (download the release or build it first).
  3. Install the optional MuseScore notation template.
  4. Add PartePlay.vst3 as an effect, load your audio, confirm the BPM/bar count — play.

Build from source

cmake --preset msvc
cmake --build --preset msvc --config Release
ctest --preset msvc    # 461 checks, 0 failures

Presets also cover ninja, linux, macos and macos-universal (x86_64 + arm64). Requires CMake 3.22+, a C++17 toolchain and JUCE 9.0.2 (via JUCE_ROOT). CI builds and tests Windows, Linux and macOS; the install scripts are PowerShell, so they are Windows-only.

No transpose, no instrument table. PartePlay deliberately does not transpose the track or fake host transport messages — host locking and honest metadata are the product. Transposition belongs to the notation, not to the reference audio.

Contribute

Conventions, the test gate and the PR contract live in CONTRIBUTING.md. Every PR must pass the 461-check suite on three platforms and carry a Signed-off-by (DCO). All UI strings go through the four-column locale table.
